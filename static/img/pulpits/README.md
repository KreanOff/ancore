# Ilustracje gadżetów

Lokalne, autorskie SVG 360 × 200 px: `assigned.svg` przedstawia listę zadań
i osobę, `statistics.svg` wykres słupkowy i kołowy. Rozszerzają styl ilustracji
szablonów Przestrzeni, z obecną paletą Ancore: biel, szare separatory,
fiolet `#5b5fc7` i jasne tło `#e8ebfa`.

Są dekoracyjne (`alt=""`), bez napisów, skryptów i zewnętrznych zasobów.
Używają ich podgląd konfiguracji gadżetu oraz pusty stan gadżetu w przeglądzie
i edytorze. Ikony kontrolek i nagłówków pochodzą nadal z `AncoreIcons`.
